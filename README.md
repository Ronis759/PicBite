# 🥗 PicBite — Android-приложение (Kotlin)

PicBite — нативная версия трекера питания «Калории»: считает калории и БЖУ по **фото**, **тексту** или **штрихкоду**.
Написано на Kotlin + Jetpack Compose. Данные дневника хранятся только на телефоне.

## Возможности

- 📸 Распознавание блюда по фото (камера или галерея) и по текстовому описанию («гречка 200 г и две сосиски»)
- 📦 Сканер штрихкодов (Google Code Scanner) + поиск в Open Food Facts; если продукта нет — ввод данных вручную, они запоминаются
- 📖 Дневник по дням: завтрак / обед / ужин / перекус, редактирование граммовки, удаление с отменой
- 📊 Кольцо калорий с целью на день и сводка БЖУ
- ⭐ Избранное: добавление частых блюд в один тап
- 🌗 Светлая / тёмная / авто тема
- 💾 Экспорт и импорт JSON — **формат совместим с веб-версией (PWA)**, дневник можно перенести между ними

## Как получить APK без Android Studio

1. Загрузи проект в свой репозиторий на GitHub (ветка `main`).
2. Открой вкладку **Actions** → workflow **Build APK** (запускается сам при каждом push, либо кнопкой *Run workflow*).
3. Когда сборка позеленеет, открой её и скачай артефакт **picbite-debug-apk** (внутри `app-debug.apk`).
4. Скопируй APK на телефон и установи (Android попросит разрешить установку из неизвестных источников).

Чтобы APK публиковался в **Releases**, создай тег: `git tag v1.0 && git push origin v1.0`.

## Сборка в Android Studio

Открой папку проекта (File → Open). Studio сама скачает всё нужное, при желании предложит сгенерировать Gradle Wrapper.
Требуется JDK 17. minSdk 26 (Android 8.0), для сканера штрихкодов нужны сервисы Google Play.

## ИИ-сервер

Распознавание еды выполняет твой прокси-сервер (Cloudflare Worker), ключ ИИ-провайдера в приложении не хранится.
В **Настройках** впиши адрес сервера и пароль — те же, что в веб-версии.

Контракт, который ожидает приложение:

```
POST <адрес сервера>
Headers: Content-Type: application/json, X-App-Token: <пароль>
Body:    {"image": "data:image/jpeg;base64,...", "note": "текст"}   // image может быть пустым

Ответ 200: {"text": "<ответ модели>"}   // допустим также ключ "result"
Ошибка:    {"error": "сообщение"}       // с кодом не 2xx
```

Модель должна вернуть JSON (можно в блоке ```json):

```json
{
  "dish": "Гречка с сосисками",
  "comment": "Оценка по фото, вес приблизительный",
  "items": [
    {"name": "Гречка варёная", "grams": 200, "kcal": 110, "protein": 4, "fat": 1, "carbs": 21},
    {"name": "Сосиска", "grams": 100, "kcal": 266, "protein": 11, "fat": 24, "carbs": 2}
  ]
}
```

`kcal`, `protein`, `fat`, `carbs` — значения **на 100 г** для указанного продукта; приложение пересчитывает их на `grams`.

## Структура

```
app/src/main/java/com/picbite/app/
├── MainActivity.kt   # весь интерфейс (Compose): дневник, диалоги, настройки
├── AppVM.kt          # состояние, сохранение в файл, бизнес-логика
├── Net.kt            # запросы к ИИ-серверу и Open Food Facts, подготовка фото
└── Models.kt         # модели данных и подсчёт БЖУ
.github/workflows/build.yml   # сборка APK в GitHub Actions
```
